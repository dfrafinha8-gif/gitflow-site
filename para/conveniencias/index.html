Perguntas que todo dono faz

Preciso trocar o sistema do caixa?

Na maioria dos casos, não. A gente verifica no diagnóstico como pegar os dados do que você já usa.

Já funciona em alguma loja?

Já construímos um painel assim para uma loja de conveniência. Por respeito ao cliente não citamos o nome, mas na conversa a gente te conta como ficou.

Serve para loja pequena?

É justamente para ela. Quando o dono é quem compra, paga e confere, cada erro de compra pesa no resultado.
